Database Demigration

Convert your encrypted database back to a regular (unencrypted) database. This will decrypt all encrypted data and restore the original schema.

Danger Zone: This operation will permanently decrypt all your data and remove encryption. Make sure you have backups before proceeding.
What happens during demigration:
  • All encrypted columns will be decrypted back to plain text
  • Hashed columns will remain hashed (one-way encryption)
  • Database schema will be simplified (no more enc_/tag_ columns)
  • Migration state will be reset
Select the encrypted database you want to restore to plain text.
Target Database Examples:
MySQL: mysql+pymysql://user:password@localhost:3306/decrypted_db
PostgreSQL: postgresql://user:password@localhost:5432/decrypted_db
SQLite: sqlite:///path/to/decrypted.db
