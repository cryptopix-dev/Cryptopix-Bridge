Migration Process Overview:
  1. Configure source database connection (original unencrypted data)
  2. Configure encrypted database connection (destination for secure data)
  3. Select tables and columns for migration
  4. Configure encryption settings for sensitive columns
  5. Execute bulk data migration with encryption

Encryption Password Configuration

Set a strong encryption password to secure your data. This password will be used to encrypt all sensitive data in your database. Important: Store this password securely - you'll need it to decrypt your data.

Optional Field: If you don't set a password here, the system will:
  1. Use your existing password from configuration (if available), OR
  2. Auto-generate a secure random password for you
Recommended: Set your own password for better control and security.
Password must be at least 12 characters long and include uppercase, lowercase, numbers, and special characters
Password Strength: Weak
At least 12 characters
One uppercase letter
One lowercase letter
One number
One special character (!@#$%^&*)
Higher security levels provide stronger encryption but may impact performance
Security Notice:
  • Your encryption password is NOT stored anywhere in the system
  • If you lose this password, your encrypted data CANNOT be recovered
  • Store this password in a secure password manager
  • Never share this password with anyone
  • Consider backing up this password in a secure location
